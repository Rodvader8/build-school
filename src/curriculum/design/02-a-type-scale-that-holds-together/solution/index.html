Method

Type that holds the page together

A scale gives every size on the page a reason. Nothing is a one-off, and nothing is guessed by eye.

Start from the body

Pick the size people read at, usually 16px, and build everything else from it. Each step up is the same multiple of the one below, so the jumps feel even.

Keep paragraphs to a comfortable line length. Past about seventy-five characters, the eye loses its place on the way back to the next line, and reading slows down.

Headings step down in order

Sub-heading

Each heading level is smaller than the one above it. The size tells the reader how the page is organised before they read a word.

Small print and captions sit one step below the body.
