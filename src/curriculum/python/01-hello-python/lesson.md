## Running Python

There's no page to preview this time. Python programs run in a terminal and print their results. Press **Run** (or the play button at the top right of the editor) and watch the Terminal panel.

```python
print("Hello")           # text goes in quotes
print(4400 + 7700)       # Python does the maths
print(13200 / 12)        # / always gives a decimal: 1100.0
```

Notice what's different from JavaScript:

- `print()` instead of `console.log()`
- comments start with `#` instead of `//`
- no semicolons at the end of lines
